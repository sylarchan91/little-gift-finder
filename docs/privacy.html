Privacy Policy

Effective November 11, 2026

This policy describes how hong keyword tool accesses, uses, stores, and shares Google user data. hong keyword tool is a personal app operated by hong. This website is its public homepage. Questions about this policy: hongze2030@gmail.com.

What the app does

hong keyword tool uses the Google Ads API, including Keyword Planner, to look up keyword search volume for hong’s own wall-art business. It is a small personal tool. It is not an advertising network, a data broker, or a hosted service that keeps Google data for other businesses.

Little Gift Finder, the gift inspiration project on this same website, is separate. It does not ask you to sign in with Google, and it does not access Google user data.

Google user data the app accesses

When someone signs in and grants access, the app requests this OAuth scope:

https://www.googleapis.com/auth/adwords

With that scope, the app can access Google Ads account data for the Google account that is signed in, through the Google Ads API. The data used in practice is keyword research data from Keyword Planner, such as keyword ideas and search volume for that account. The app accesses only the signed-in user’s own Google Ads account data. It does not access Google accounts that person cannot access.

How Google user data is used

Google user data is used for keyword research only. The app looks up keyword search volume for hong’s wall-art business. It does not use Google user data to create or change ads, to target advertising, to sell products, or for any other purpose.

How Google user data is stored

OAuth tokens are stored locally on the owner’s machine only. The app does not store Google user data or tokens on a server. It does not write them to a remote database. Keyword results stay on the machine where the app is running. Removing the app’s local data on that machine deletes the locally stored tokens.

Sharing and selling

hong keyword tool does not share Google user data with third parties. It does not sell Google user data. It does not rent or transfer that data to advertisers, analytics services, data brokers, or any other third party. Calls to the Google Ads API go from the machine running the app to Google. This website does not receive that data.

Google API Services User Data Policy, including Limited Use

hong keyword tool’s use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

  • Google user data is used only to provide the user-facing keyword research feature described in this policy.
  • The app does not transfer Google user data to others. Limited Use allows a few narrow transfers, such as security, legal compliance, or a merger with the user’s prior consent. This app does not make those transfers.
  • People other than the signed-in user do not read this Google user data. The signed-in user can see their own keyword results in the app. hong does not allow anyone else to read that data, unless the user gives explicit permission for a specific disclosure, it is required for security, or the law requires it.
  • Google user data is not used or transferred for serving ads, including retargeting, personalized advertising, or interest-based advertising.
  • Google user data is not used or transferred to determine credit-worthiness or for lending.
  • Google user data is not sold.

How to revoke access

You can revoke hong keyword tool’s access to your Google account at any time on Google’s permissions page:

https://myaccount.google.com/permissions

Open that page while signed in to the Google account you connected, select hong keyword tool, and remove its access. After you revoke access, the app cannot call the Google Ads API for that account until you grant permission again. You can also delete tokens stored on the machine by removing the app’s local data.

Retention and deletion

hong does not keep a server copy of Google user data, so there is no server-side archive to delete. Revoke access on the Google permissions page above to stop further access. Delete the app’s local data on the machine to remove tokens stored there. For a privacy question or a deletion request, email hongze2030@gmail.com.

This website

These pages are static files. They do not collect Google Ads data and they do not set their own analytics cookies. Little Gift Finder keeps what you type in memory in the browser tab and drops it when you reload. GitHub Pages hosts the site and may record ordinary request logs, as described in GitHub’s privacy statement.

Children

hong keyword tool is not directed at children, and it does not knowingly request Google user data from children.
