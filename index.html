hong keyword tool

hong keyword tool is a small personal app. It uses the Google Ads API (Keyword Planner) to look up keyword search volume for hong’s own wall-art business. To do that, it requests access to the signed-in user’s own Google Ads account data. OAuth tokens stay on the owner’s machine only. The app stores nothing on a server and does not share or sell Google user data.
